# E-Commerce Client Application (Angular)

The frontend Single Page Application (SPA) for the E-Commerce platform, built using Angular and TypeScript.

## Features
- **Storefront & Catalog**: Browse products with live inventory display.
- **Cart Management**: Add/remove products and adjust cart items.
- **Checkout Flow**: Complete checkout and order creation.
- **Order Tracking & Approval**: View past orders, check statuses, and approve pending orders.
- **Admin Dashboard**: Manage products, adjust inventory quantities, import Excel/CSV files, and manage orders.
- **Real-time Notifications**: Connected to SignalR hub for live order status updates.

## Development Setup

1. Install dependencies:
   ```bash
   npm install
   ```

2. Start the development server:
   ```bash
   npm start
   ```

3. Navigate to `http://localhost:4200/` in your browser.
